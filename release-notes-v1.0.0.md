## Twinkle Tray Lite 1.0.0

基于 [Twinkle Tray](https://github.com/xanderfrangos/twinkle-tray) 1.17.2 的精简版，保留核心的显示器亮度控制，移除非必要功能。

A lightweight build based on [Twinkle Tray](https://github.com/xanderfrangos/twinkle-tray) 1.17.2, keeping core brightness control and removing non-essential features.

---

### 中文

**本版改动**

- 移除自动更新（含 UI）
- 移除 GA4 遥测（含 UI）
- 移除 UDP 远程控制（含 UI）
- 移除 Apple Studio Display 支持（含 UI）
- 移除旧版设置迁移逻辑，设置格式固定为 v1.17.2
- 托盘图标主题跟随系统，修复任务栏固定区图标不刷新
- debug 页全部汉化（i18n，中/英）
- 平衡亮度页 `Input` / `Output` / `Calibration Point` 汉化
- 新增关于页（版本、GitHub、许可证、原作者）
- 版本号 1.0.0，AppID `com.zerin.twinkle-tray-lite`
- 仅支持 Windows x64

**安装**

下载 `TwinkleTrayLite-Setup-1.0.0-x64.exe`，默认安装到 `%LOCALAPPDATA%\Programs\Twinkle Tray`，无需管理员权限。

### English

**Changes**

- Removed auto-update (including UI)
- Removed GA4 telemetry (including UI)
- Removed UDP remote control (including UI)
- Removed Apple Studio Display support (including UI)
- Removed legacy settings migration; settings format fixed at v1.17.2
- Tray icon follows system theme; fixed pinned tray icon not refreshing
- Debug page fully localized (i18n, Chinese/English)
- Localized Input/Output/Calibration Point on the Balance Brightness page
- Added About page (version, GitHub, license, original author)
- Version 1.0.0, AppID `com.zerin.twinkle-tray-lite`
- Windows x64 only

**Install**

Download `TwinkleTrayLite-Setup-1.0.0-x64.exe`. Installs to `%LOCALAPPDATA%\Programs\Twinkle Tray` by default, no admin required.
